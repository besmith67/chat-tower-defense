# Chat Tower Defense

A tower defense game where the streamer defends and the chat attacks.

Viewers on Twitch, YouTube, or Kick spam emotes and words. Every message can become a monster with traits derived from its text. The streamer builds towers that counter specific kinds of words and emotes, so both sides adapt to each other in real time. Streams with a quiet chat, or no chat at all, fall back to a simulated chat.

See [docs/DESIGN.md](docs/DESIGN.md) for the game design.
